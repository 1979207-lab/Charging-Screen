# Charging Screen PRO

Нативное Android-приложение на Kotlin.

- minSdk 26 / targetSdk 34
- AMOLED-чёрный экран, часы 12/24 и дата
- Анимированное кольцо с молнией
- 4 цветовые схемы и 4 варианта индикатора
- Мощность зарядки и температура батареи (если устройство предоставляет данные)
- Оценка времени до 100% через системный API на поддерживаемых устройствах
- Настройка яркости и ночное затемнение
- Чувствительность свайпа
- Звуковой сигнал при 100%
- Foreground service и восстановление мониторинга после перезагрузки

## APK
Откройте **Actions → Android APK**. После успешной сборки скачайте артефакт **Charging-Screen-PRO-debug**.

**Ограничение Android:** начиная с Android 10 система ограничивает запуск Activity из фонового режима. Автоматический показ поверх блокировки зависит от версии Android, оболочки и разрешений; уведомление службы остаётся резервным способом открыть экран. Для Google Play служба типа specialUse должна соответствовать правилам публикации.
