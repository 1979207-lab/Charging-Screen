# Charging Screen PRO

Нативное Android-приложение на Kotlin для AMOLED-экрана зарядки.

## Сборка
Откройте вкладку Actions и запустите workflow **Android APK**. Готовый APK появится в Artifacts.

Требования: Android 8.0+ (minSdk 26), targetSdk 34, JDK 17.

Функции: анимированный индикатор с молнией, часы 12/24, 4 цвета, мощность зарядки, температура аккумулятора, оценка времени до 100%, яркость, 4 темы экрана, звуковое оповещение 100%, настройка свайпа.
